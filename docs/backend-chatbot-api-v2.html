1. Laravel setup

CHATBOT_API_URL=http://127.0.0.1:8001
  • Header: Content-Type: application/json
  • AvalAI key lives only in Python .env — Laravel does not need it
  • Default max_output_tokens: 500 · max history turns: 20
  • VPS .env: no quotes around values (systemd)

2. Chat memory (Laravel owns history)

Python is stateless. Laravel loads prior turns from DB, sends history, saves user + assistant after each call.

Vue → Laravel (chat_sessions + chat_messages)
        → POST /v1/bots/{bot_id}/chat  { message, history[] }
        ← { reply, history_turns_used }
   Laravel saves both turns
  • history = prior turns only — exclude current message
  • Separate sessions per bot_id (teacher vs story)
  • Reference PHP: docs/laravel/

13. Common errors

HTTPWhen
404Unknown bot id
422Missing fields (e.g. answer for open, selected_option_ids for MCQ)
502AvalAI failure or bad JSON from model
503Missing AVALAI_API_KEY on Python service

Upstream resource_not_found on model → use a model that supports /v1/chat/completions (e.g. gpt-5.6-luna).
