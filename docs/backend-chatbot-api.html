Serendipity Chatbot API

Base URL: http://127.0.0.1:8001
Contents Setup Health List bots Teacher chat Story chat Assess Errors

1. Setup for Laravel

Add to Laravel .env:

CHATBOT_API_URL=http://127.0.0.1:8001
  • All requests go to this base URL from the server (not the browser).
  • Header for JSON bodies: Content-Type: application/json
  • Interactive Swagger (on VPS only): http://127.0.0.1:8001/docs
  • This API is not public on the internet; only reachable from the VPS.
Do not call these URLs from the Vue frontend as http://89.44.241.36/v1/... — that path still serves the dashboard. Laravel must call 127.0.0.1:8001.

4. Teacher chat

POST http://127.0.0.1:8001/v1/bots/teacher/chat

Full request

POST http://127.0.0.1:8001/v1/bots/teacher/chat
Content-Type: application/json

{
  "message": "سلام! یک جمع ساده بهم یاد بده",
  "history": [],
  "user_prompt": null,
  "model": null
}

With conversation history

POST http://127.0.0.1:8001/v1/bots/teacher/chat
Content-Type: application/json

{
  "message": "پس ۲+۳ چند میشه؟",
  "history": [
    { "role": "user", "content": "سلام! یک جمع ساده بهم یاد بده" },
    { "role": "assistant", "content": "باشه! مثلاً ۱+۱ میشه ۲." }
  ]
}

Fields

FieldRequiredNotes
messageyesCurrent user message (string)
historynoArray of prior turns; roles: user | assistant
user_promptnoExtra instructions for this call
modelnoOverride model; omit for server default

cURL

curl -s http://127.0.0.1:8001/v1/bots/teacher/chat \
  -H "Content-Type: application/json" \
  -d '{
    "message": "سلام! یک جمع ساده بهم یاد بده",
    "history": []
  }'

Response 200

{
  "bot_id": "teacher",
  "reply": "سلام! بیا با هم جمع کنیم…",
  "model": "deepseek-v4-flash"
}

6. Assess child answer

POST http://127.0.0.1:8001/v1/bots/assess

Scores the child’s answer against each objective under each sub-area of each area.

Full request

POST http://127.0.0.1:8001/v1/bots/assess
Content-Type: application/json

{
  "question": "۲ + ۳ چند می‌شود؟",
  "answer": "۵",
  "user_prompt": null,
  "model": null,
  "areas": [
    {
      "name": "ریاضی",
      "sub_areas": [
        {
          "name": "جمع",
          "objectives": [
            "می‌تواند دو عدد یک‌رقمی را جمع کند",
            "نتیجه را درست می‌نویسد"
          ]
        }
      ]
    }
  ]
}

Fields

FieldRequiredNotes
questionyesQuestion shown to the child
answeryesChild’s answer text
areasyesNested list: area → sub_areas → objectives
user_promptnoExtra assessment instructions
modelnoOptional model override

cURL

curl -s http://127.0.0.1:8001/v1/bots/assess \
  -H "Content-Type: application/json" \
  -d '{
    "question": "۲ + ۳ چند می‌شود؟",
    "answer": "۵",
    "areas": [
      {
        "name": "ریاضی",
        "sub_areas": [
          {
            "name": "جمع",
            "objectives": ["می‌تواند دو عدد یک‌رقمی را جمع کند"]
          }
        ]
      }
    ]
  }'

Response 200

{
  "assessments": [
    {
      "area": "ریاضی",
      "sub_area": "جمع",
      "objective": "می‌تواند دو عدد یک‌رقمی را جمع کند",
      "status": "met",
      "score": 1.0,
      "feedback": "پاسخ درست است."
    }
  ],
  "summary": "کودک مفهوم جمع را درست نشان داده است."
}
FieldMeaning
statusmet | partial | not_met
score0.0–1.0
feedback / summaryPersian, teacher-facing

7. Common errors

HTTPWhen
404Unknown bot id (e.g. /v1/bots/math/chat)
422Invalid / missing body fields
502Upstream LLM failure or bad assess JSON
503API misconfigured (missing AvalAI key on Python side)
